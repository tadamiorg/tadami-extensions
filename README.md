# Tadami extensions

The official extension repository of [Tadami](https://github.com/tadamiorg/tadami). Tadami downloads the extensions listed here into its own storage and loads them to browse, search and watch anime.

The files are generated by the **Release extensions** workflow of [tadami-extensions-source](https://github.com/tadamiorg/tadami-extensions-source). Don't edit them by hand; only this README is written by hand.

## Use it in Tadami

The repository is added by default. Its URL is:

```
https://raw.githubusercontent.com/tadamiorg/tadami-extensions/main
```

If you removed it, add it back from **Extensions → menu → Extension repositories** (Tadami 1.12.0 or later).

Its extensions are signed with the official key. Its SHA-256 certificate fingerprint is:

```
11dec208a209773efdc5348af5de709ca9af067e9154d1dd3c6abdb0fa3cc200
```

## Layout

| Path | Content |
|---|---|
| `index.min.json` | The list of extensions that Tadami reads (`index.json` is the same, indented). |
| `apk/` | The signed extension APKs, named `tadami-<lang>.<name>-v<version>.apk`. |
| `icon/` | The icons, named `<package>.png`. |
| `repo.json` | The repository's name and signing key fingerprint. It's written by the next release. |

### `index.min.json`

A JSON array, one entry per extension:

```json
{
  "name": "Tadami: AnimeSama",
  "pkg": "com.sf.tadami.extension.fr.animesama",
  "apk": "tadami-fr.animesama-v1.6.32.apk",
  "lang": "fr",
  "code": 32,
  "version": "1.6.32",
  "sha256": "f408a768fdb62a28c3c6f5d084ca1516cf85a59076dab2450f08f843f8ece285",
  "size": 195158,
  "sources": [
    { "name": "AnimeSama", "lang": "fr", "id": "2", "baseUrl": "https://anime-sama.to", "versionId": 32 }
  ]
}
```

- `version` is `<extensions-lib version>.<code>`: `1.6.32` is built against lib 1.6, with version code 32.
- Tadami checks the downloaded APK against `sha256` and `size` before installing it.
- `sources[].id` is the source ID, which never changes once published. Official IDs are reserved for the official signing key.

### `repo.json`

```json
{
  "meta": {
    "name": "Tadami",
    "shortName": "Tadami",
    "website": "https://github.com/tadamiorg/tadami-extensions-source",
    "signingKeyFingerprint": "11dec208a209773efdc5348af5de709ca9af067e9154d1dd3c6abdb0fa3cc200"
  }
}
```

When you add a repository, Tadami shows its name and offers to trust the extensions signed with `signingKeyFingerprint`.

## Make your own extensions

Create your own extensions repository from the [tadami-extensions-source](https://github.com/tadamiorg/tadami-extensions-source) template (**Use this template**). Its README explains how to write, sign and publish extensions, and how users add your repository in Tadami.
